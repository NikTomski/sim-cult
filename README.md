# Орден Тихой Козы — симулятор культа

Текстовая игра про управление культом. Вдохновлена Cult of the Lamb и Worship.

## Запуск

    python main.py            # случайная партия
    python main.py 42         # партия с фиксированным seed

Нужен Python 3.10+.

## Структура

- `main.py` — точка входа и игровой цикл
- `game/models.py` — Cult, Follower, Event, Choice
- `game/engine.py` — выбор событий, эффекты, условия победы и поражения
- `game/ui.py` — весь ввод/вывод (print/input только здесь)
- `content/events.py` — события; добавлять новые сюда

## Личные сюжеты

У события может быть `subject` — функция, выбирающая героя (последователя). Пока событие идёт,
герой доступен как `cult.subject`. Выбор игрока запоминается во `flags` последователя
(`"tolerated"`, `"renounced"`, `"herald"` ...), а следующие события в цепочке проверяют эти флаги.
Примеры: цепочка Игната (`ignat_secret` → `ignat_gift` / `ignat_grudge`), Марта-глашатай, видение Агаты.

## Как добавить событие

Создай `Event(...)` в `content/events.py` и добавь его в список `EVENTS`.
Текст события и исходов может быть строкой или функцией `lambda c: ...`,
которая подбирает тон по состоянию культа (`by_mood`).
