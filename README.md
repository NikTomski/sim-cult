# Орден Тихой Козы — симулятор культа

Текстовая игра про управление культом. Вдохновлена Cult of the Lamb и Worship.
Есть две версии на одном движке: консольная и браузерная (Flask).

## Запуск: браузерная версия

Нужен Python 3.10+.

    python -m venv .venv
    .venv\Scripts\activate          # Windows;  macOS/Linux: source .venv/bin/activate
    pip install -r requirements.txt
    python app.py

Открой http://127.0.0.1:5000. Управление: кнопки или цифры 1-9 на клавиатуре,
✎ рядом с именем переименовывает культ и последователей.

## Запуск: консольная версия

    python main.py            # случайная партия
    python main.py 42         # партия с фиксированным seed

В консоли: `r` — переименовать культ, `f` — последователя, `q` — выход
(на русской раскладке `к`, `а`, `й`).

## Структура

    main.py              консольная версия
    app.py               веб-сервер (Flask, JSON API)
    web/                 страница: index.html, style.css, game.js
    game/session.py      пошаговая игровая сессия — единый движок для консоли и веба
    game/engine.py       выбор событий, эффекты, победа/поражение, переименование
    game/models.py       Cult, Follower, Event, Choice
    game/ui.py           ввод/вывод консоли
    content/events.py    события и личные сюжеты (добавлять новые сюда)
    Procfile             команда запуска для хостинга

## API (JSON)

Партия определяется заголовком `X-Session` (токен выдаёт `POST /api/new`).

| Метод и путь                | Что делает                                    |
|-----------------------------|-----------------------------------------------|
| `POST /api/new`             | новая партия, возвращает `token` и `view`     |
| `GET  /api/state`           | текущее состояние                             |
| `POST /api/start`           | основать культ (из фазы setup в день 1)       |
| `POST /api/choose`          | `{"index": 0}` — выбрать вариант события      |
| `POST /api/next`            | следующий день                                |
| `POST /api/rename/cult`     | `{"name": "..."}`                             |
| `POST /api/rename/follower` | `{"index": 0, "name": "..."}`                 |

Фазы игры (`view.phase`): `setup → event → outcome → event → … → over | won`.
Ошибки: 400 — неверные данные, 401 — сессия не найдена, 409 — действие не к месту в этой фазе.

## Выкладка на хостинг

GitHub Pages не подойдёт: ему нужен сервер с Python. Подойдёт любой хостинг,
запускающий Flask/WSGI (Render, Railway, Fly.io, PythonAnywhere и т. п.; условия
бесплатных тарифов меняются, проверяй актуальные).

Команда запуска (она же в `Procfile`):

    gunicorn -w 1 --threads 8 -b 0.0.0.0:$PORT app:app

**Важно: ровно один рабочий процесс (`-w 1`).** Партии хранятся в памяти процесса.
При нескольких процессах игрок будет попадать на разные копии сервера и «терять» игру.
После перезапуска сервера активные партии сбрасываются (страница сама начнёт новую
и скажет об этом). Партия без активности живёт 6 часов, одновременно держится
не больше 2000 партий.

Если понадобятся несколько процессов или сохранения между перезапусками, партию
нужно сделать сериализуемой и хранить в БД или Redis (в `GameSession` для этого
всё готово: состояние лежит в `Cult`, `rng` и фазе).

## Безопасность

- Имена игроков выводятся на странице только как текст (никакого `innerHTML`).
- Заголовок CSP `default-src 'self'` (скрипты и стили только свои), `nosniff`, запрет встраивания.
- Тела запросов ограничены 4 КБ, имена по длине (40 / 24 символа) и по дубликатам.

## Личные сюжеты

У события может быть `subject` — функция, выбирающая героя (последователя). Пока событие идёт,
герой доступен как `cult.subject`. Выбор игрока запоминается во `flags` последователя
(`"tolerated"`, `"renounced"`, `"herald"` ...), а следующие события в цепочке проверяют эти флаги.
Примеры: цепочка Игната (`ignat_secret` → `ignat_gift` / `ignat_grudge`), Марта-глашатай, видение Агаты.

Сюжеты находят героев по стабильному ключу (`Follower.key`, `by_key`), а не по имени, поэтому
переименование ничего не ломает. В текстах имена используются только в именительном падеже
(склонять произвольные имена нельзя).

## Как добавить событие

Создай `Event(...)` в `content/events.py` и добавь его в список `EVENTS`.
Текст события и исходов может быть строкой или функцией `lambda c: ...`,
которая подбирает тон по состоянию культа (`by_mood`).
